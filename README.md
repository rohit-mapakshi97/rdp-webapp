# RDP Classifier Web Application  

## Overview  
The **RDP Classifier Web Application** is a web-based interface built using **Spring Boot** and **Thymeleaf** to interact with the **RDP Classifier**, a naive Bayesian classifier designed for rapid taxonomic placement of rRNA sequences.  

This application allows users to classify bacterial, archaeal, and fungal rRNA sequences, providing taxonomic assignments with confidence estimates from domain to genus.  

## Features  
- **User-friendly Web Interface** – Built using Thymeleaf for dynamic HTML rendering  
- **Seamless Backend Integration** – Powered by Spring Boot for efficient request handling  
- **Taxonomic Classification** – Supports bacterial and archaeal 16S rRNA sequences and fungal LSU sequences  
- **Confidence Estimates** – Provides confidence scores for taxonomic assignments  
- **Scalable & Adaptable** – Can be extended for additional bacterial taxonomies  

## Technologies Used  
- **Spring Boot** – Backend framework  
- **Thymeleaf** – Templating engine for frontend rendering  
- **Java** – Core application logic  
- **HTML/CSS/JavaScript** – Frontend for user interaction
